# Iliakis et al. (2026) analysis code

Code and supporting data for *Striatal interneuron microcircuits gate reinforcement to stabilize adaptive choice*. Analyses are organized by workflow; each directory's README describes its inputs, scripts, and current reproduction status.

| Directory | Figure panels | Guide |
| --- | --- | --- |
| [`opto_behavior/`](opto_behavior/) | Figure 4C-F optogenetic behavior | [Figure 4 README](figure4/README.md) |
| [`rl_glm_hmm/`](rl_glm_hmm/) | Figure 5 and Figure S15 computational analyses | [RL-GLM-HMM README](rl_glm_hmm/README.md) |

The `rl_glm_hmm/upstream_glmhmm/` directory is a pinned Git submodule from Iris Stone's GLM-HMM project. Its provenance and setup instructions are in the [RL-GLM-HMM README](rl_glm_hmm/README.md).
